# Northgate Station — Air Quality Dataset

## Data Release Status

**🚧 Data collection in progress — not yet released**

This repository will contain the curated hourly air-quality measurements collected at the Northgate Station monitoring station, together with the quality-control pipeline and the data dictionary. The first calibration cycle is still running and the measurements have not yet been validated; the dataset will be published once the calibration report has been signed off.

## Site Information
